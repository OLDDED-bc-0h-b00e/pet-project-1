# «Уголёк» — одностраничный сайт кофейни

## Цель
Портфолио-проект: адаптивный (mobile-first) одностраничный сайт для вымышленной кофейни «Уголёк» в историческом центре. Чистый HTML/CSS/JS, без фреймворков, без сборки.

## Структура файлов
```
index.html
style.css
script.js
images/            — 8-10 скачанных фото (интерьер, кофе, выпечка)
```

## Разделы страницы
1. Hero — полноэкранный блок, название, слоган, фото, кнопка «Посмотреть меню» (скролл к меню)
2. О нас — 2-3 абзаца истории + фото интерьера/команды
3. Меню — 8 карточек (кофе + выпечка), название/цена/иконка или фото
4. Галерея — сетка 6-8 фото
5. Часы работы и адрес — текстовый блок + placeholder-iframe карты
6. Контакты/CTA — телефон, соцсети (VK/Telegram/Instagram, нерабочие ссылки), демо-форма (без реальной отправки)
7. Футер — копирайт

## Визуальный стиль
- Цвета: терракотовый `#C1673B`, крем `#F5EBDD`, тёмный кофейный `#3B2A20`, тёплый бежевый фон
- Заголовки: Google Fonts **Fraunces** (serif)
- Текст: Google Fonts **Inter** (sans-serif)
- Текстура: лёгкий CSS SVG-паттерн (крафт-бумага/дерево) фоном секций
- Анимации: fade-in-up при скролле через `IntersectionObserver`, плавный scroll к меню

## Контент (придуман для демо)
- История: кофейня в отреставрированном купеческом доме XIX века
- Меню (8 позиций, 150–350 ₽): эспрессо, капучино, флэт уайт, раф, какао, круассан, чизкейк, шоколадный брауни
- Адрес: вымышленный, «ул. Кузнечная, 12, старый город»
- Соцсети/телефон/карта — плейсхолдеры

## Изображения
8-10 тематических фото с Unsplash, скачанных локально в `/images` (лицензия Unsplash — свободное использование), сайт работает offline.

## Проверка
Открыть в браузере Claude, проверить desktop и мобильную раскладку (375px), проверить работу анимаций и кнопки скролла.
